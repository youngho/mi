# 정적 투과빔 1줄 — 배선과 플래시

 copier는 **전원 끄고 커넥터를 빼도 된다.** 이 스케치는 모터를 구동하지 않는다.

스케치: `teensy41/throughBeamGate/throughBeamGate.ino`  
판정: [docs/bds-gonogo-throughbeam.md](../../docs/bds-gonogo-throughbeam.md)

**Teensy는 한 장만** 쓴다. (L 또는 R 아무거나)

---

## 1. 플래시

Arduino IDE:

1. 보드 **Teensy 4.1**
2. USB Type → **Serial** (Mouse 필요 없음)
3. `throughBeamGate.ino` 열고 Upload
4. 시리얼 115200. TFT에 `GATE 1-BEAM` 이 나오면 이 펌웨어다.

예전 `laserModuleL` / `laserModuleR` 을 덮어쓴다. 커튼 펌웨어가 필요하면 나중에 다시 올리면 된다.

---

## 2. 전기 배선 (핀은 기존과 같음)

전기는 바꾸지 않는다. **센서의 위치와 보는 방향**만 바꾼다.

| 모듈 | Teensy | 비고 |
|------|--------|------|
| 레이저 RED (+) | 3.3V 또는 LM2596 5V | 기존 NPN 회로 |
| 레이저 BLACK (−) | NPN Collector | Pin9 → 1kΩ → Base |
| LM393 VCC | **3.3V** | 5V 금지 |
| LM393 GND | GND | |
| LM393 DO | Pin **5** | |
| LM393 AO | **A1 (Pin 15)** | A0=TFT BL |
| TFT | 기존 그대로 (7/8/10/11/13/14) | |

모터 24V는 끈다. CLK/LD/S 케이블은 꽂아 둬도 이 스케치는 안 쓴다.

---

## 3. 광학 (이게 새 연결)

```
  [레이저] ──────── 빔 ────────► [LM393 포토다이오드]
     ▲                              ▲
  Teensy 옆                      맞은편 (전선으로 연장)
              손가락 / BB가 여기를 가로지름
```

- 레이저와 센서를 **같은 구석에 두지 않는다.**  copier 옆에서 테이프를 보던 배치를 버린다.
- 포토다이오드가 **레이저 빛을 정면으로** 보게 한다. 벽·테이프 반사가 아니다.
- 책상 위 **30~80cm** 로 먼저 맞춘다. 벽 폭은 손가락·BB가 찍힌 뒤에.

라인 레이저면 부채가 얇은 부분(밝은 줄)이 PD를 지나게 한다. 점 렌즈가 있으면 점이 더 쉽다.

트리머: `laser on` 후 빔이 PD를 칠 때 DO-LED가 수광 쪽이 되게. 손을 넣으면 반대.

---

## 3.1 조리개 (산란 차단 — BB 시험 전에)

손가락은 되고 BB가 안 되면, 탄이 가려도 **옆에서 들어온 산란**이 PD를 계속 채우는 경우가 많다. 구멍이 작을수록 직광만 남는다.

구멍만 뚫지 말고, **짧은 관**을 붙인다. 구멍은 시야를 줄이고, 관은 옆빛을 막는다.

```
  [레이저] ────────►  |===== 관 =====|● PD
                      입구 ø 1~2mm
```

만드는 법 (있는 것):

1. LM393 포토다이오드 앞을 **검정 테이프**로 가린다.
2. 핀으로 **1~2mm** 구멍. 처음엔 작게. 안 보이면 조금 키운다.
3. 구멍 앞에 **빨대·열수축 튜브·검은 종이 통** 3~5cm. 축이 레이저를 향하게.
4. 관 안은 반짝이면 안 된다. 안쪽에 테이프를 한 겹 더 둘러도 된다.

맞추기:

1. `laser on` → 관을 **레이저 쪽으로** 미세하게 돌린다. `[beam] 1` 이 되면 직광이 구멍으로 들어온 것이다.
2. 구멍 **바로 앞**을 손가락으로 가림 → `[beam] 0`. 여기도 1이면 산란이 아직 있다. 관을 더 길게, 구멍을 더 작게.
3. `sensor` 의 `AO`가 0 또는 1023에 박히면 아직도 과포화. 구멍/휴지.
4. 그다음 레이저와 구멍 **사이 줄**에 BB.

펌웨어는 그대로다. 전기 핀도 그대로다.

## 5. LM393 모듈은 느리다 (실험 결과)

천천히 지나가는 드라이버·손가락은 되고, **빨리 지나가면 안 된다.**  
이건 정렬이 아니라 **LM393 모듈 수광/비교기가 밀리초 급**이라서다. 조리개·펌웨어 `irq`로는 BB를 못 잡는다.

LM393 모듈은 이 실험에서 폐기한다.

### 다음에 살 것 (카메라 아님)

- **BPW34** (또는 BPW34FA) PIN 포토다이오드 — 몇천 원
- 저항 **1kΩ** (4.7k보다 빠름. 이미 4.7k면 바꿔 본다)
- 조리개(관)는 그대로

### A1 배선 (LM393의 A1/DO는 뺀다)

```
3.3V ──► BPW34 음극(cathode, 표시/띠)
BPW34 양극 ──┬── A1 (Pin 15)
              └── 1kΩ ──► GND
```

레이저가 켜져 있을 때 `sensor`의 `AO`가 올라가야 한다. 안 움직이면 다이오드 방향을 바꾼다. 3.3V만. 5V 금지.

```
laser on
mode adc
sensor
```

`AO`가 밝은/어두운 중간쯤이 되게 `aoth 숫자` (예: 밝은 800, 어두운 100이면 `aoth 400`).  
`flip` 은 adc에서 명암 방향을 바꾼다.

1. 느린 드라이버 → `[hand]`
2. 빠른 드라이버 → `[hand]` 수 ms 또는 `[bb]`
3. BB → 쏠 때만 `[bb] w=` 가 **수십~수백 us**. 드라이버 끝에 붙는 10us는 잡음일 수 있다.

`hb adc ao= aoth= sps=` 의 sps가 수십만이면 샘플은 충분하다. 그래도 BB가 없고 드라이버만 `[hand]` 수 ms면, 전압이 탄만큼 빨리 안 떨어지는 것이다. 그때는 ADC가 아니라 비교기 IC(MCP6561 / LM311)다.


`mode irq` 는 예전 LM393 DO. 빠른 물체 시험에 쓰지 않는다.


```
laser on
sensor
```

| 로그 | 의미 |
|------|------|
| `[beam] 1` | 지금 수광 (정렬됨) |
| `[beam] 0` | 암흑. 손을 넣었거나 빔이 PD를 벗어남 |
| `[hand] w=…ms` | 긴 차단 → 손가락 정렬 OK |
| `[bb] w=…us` | 짧은 차단 → BB 후보 |
| `hb beam= ao=` | 1초마다. TFT 말고 USB에만 |

`sensor` | `flip` | `reset`(카운트) | `cls`(LCD 지움) | `help`  
`AO`가 0 또는 1023에 박히면 휴지/거리/트리머.

1. 손으로 빔을 가렸다 떼기 → `[hand]` 와 `[beam] 0↔1`
2. 산란이 의심되면 §3.1 조리개 후 다시 1
3. 그 줄을 BB가 지나가게 10발 → `[bb]` 개수

손가락만 되고 `[bb]`가 없으면, 먼저 조리개. 그래도 없으면 LM393이 느린 것. 카메라를 사지 말고 빠른 포토다이오드로 같은 배치만 바꾼다.

# hangul

한글 키워드를 자바스크립트로 컴파일한다.

## 문법

```
함수 더하기(가, 나) {
  반환 가 + 나
}
변수 합 = 더하기(1, 2)
합 = 합 + 1
만약 합 > 0 {
  출력 합
} 아니면 {
  출력 0
}
동안 합 > 0 {
  합 = 합 - 1
}
```

- 정수와 `+` `-` `*` `/`. 나눗셈은 소수점을 버리고 0 쪽으로 맞춘다.
- 비교 `==` `!=` `<` `>` `<=` `>=`. 참은 1, 거짓은 0.
- `아니면`은 빼도 된다. `//` 뒤는 주석이다.

## 실행

저장소 루트에서:

```bash
node hangul/cli.js hangul/examples/더하기.hangul -o /tmp/더하기.js
node /tmp/더하기.js
```

`-o`를 생략하면 같은 이름의 `.js`를 만든다.

테스트:

```bash
cd hangul && node --test
```
